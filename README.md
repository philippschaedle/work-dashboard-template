# work-dashboard-template

A [cookiecutter](https://cookiecutter.readthedocs.io/)/[cruft](https://cruft.github.io/cruft/)
template for a personal or team work dashboard managed with Claude Code: a live
`DASHBOARD.md` index over your real tracker (Jira/Confluence/Linear/whatever) and GitHub,
a `TASKS.md` for everything they don't track, one Markdown file per meeting under `notes/`,
and a dated `PROGRESS.md` log — plus the `CLAUDE.md` operational rules that make Claude
Code follow all of that automatically.

## Create a new dashboard from this template

With [uv](https://docs.astral.sh/uv/) installed, either run it without installing anything:

```bash
uvx cruft create https://github.com/philippschaedle/work-dashboard-template
```

or install `cruft` as a persistent tool first (useful since you'll also want it later for
`cruft check`/`cruft update`):

```bash
uv tool install cruft
cruft create https://github.com/philippschaedle/work-dashboard-template
```

You'll be prompted for a project name, your primary tracker's name/URL, your GitHub
username, and a couple of key repo names — cruft writes those into the generated files
and records the template commit in `.cruft.json` so you can pull in future template
updates with `cruft update`.

## What's in the generated project

See the generated project's own `README.md` and `CLAUDE.md` — this template's README
intentionally doesn't duplicate that content, since it lives with the template variables
substituted in the output, not here.

## Updating an existing dashboard from a newer template version

From inside a project generated by this template (swap in `uvx cruft` for either command if
you didn't install it persistently):

```bash
cruft check    # is there a newer template commit?
cruft update   # apply the diff, review, resolve any conflicts, commit
```

## Linting

The generated project ships its own `.markdownlint.yaml`, `.pre-commit-config.yaml`, and
`.github/workflows/lint.yml` — Markdown linting is part of what you get, not something you
have to bolt on afterward.
