# Tasks

**This file holds only what the primary tracker and GitHub don't already track.** See
`CLAUDE.md` for the full rule.

## How to use this file

- **P1 (Immediate / Blockers)** — needs to happen now or is blocking other work. Tag with
  an estimated time, e.g. `[30m]`, `[2h]`.
- **P2 (Scheduled / High Value)** — important, not urgent. Has a plan but not necessarily
  a deadline today.
- **P3 (Backlog / Someday)** — worth doing eventually, not scheduled.
- Within each priority, tasks are grouped under a `###` sub-heading by the initiative they
  support, or "Other" for personal/admin items.
- **Before adding a task, check the tracker and GitHub open issues first.** If it's already
  tracked there, don't add it here — link to it from DASHBOARD.md instead.
- When a task is checked off (`- [x]`), it gets removed from here — no separate archive.
